## Notes

- **OpenClaw's pi dependency:** the loop is a private workspace package adapted from Pi code (`THIRD_PARTY_NOTICES.md:19-24`). The only live `@earendil-works/pi-*` dependency is `pi-tui`, used for the terminal UI. Codex and ACP backends bring their own loops.
- **OpenClaw extensions:** about 190 `extensions/*` dirs, and most channels, providers and memory backends are plugins. Many have their own versions and publish to npm and ClawHub. Root `package.json` lists only core dependencies, and the bundled `@openclaw/ai` and `@openclaw/agent-core` are workspace-private or inlined.
- **OpenClaw desktop split:** the macOS app is native Swift/SwiftUI, and the Linux companion is Tauri 2 with a vanilla-JS UI. The Tauri config also has macOS and Windows paths. The Control UI web app uses Solid 2.0 release candidates. Only `openclaw-gateway-client` and `openclaw-node-host` are cargo workspace members (`crates/Cargo.toml:2`); the two iroh crates are napi and uniffi bindings.
- **Hermes dependency pins:** every core dependency in `pyproject.toml` is gated by `python_version >= '3.14'` (`pyproject.toml:10-13`), so installs on older Pythons behave differently. Provider SDKs (`anthropic` and others), messaging libraries, MCP, ACP, voice and keyring are optional extras (`pyproject.toml:225-500`), and some are lazy-installed through `hermes pm`. WhatsApp runs as a separate Node bridge.
- **Hermes one backend, many UIs:** the Ink TUI, Electron desktop and dashboard `/chat` all talk to one Python `tui_gateway`. The dashboard embeds the real TUI over a PTY rather than rebuilding chat in React (`web/AGENTS.md:7-17`).
