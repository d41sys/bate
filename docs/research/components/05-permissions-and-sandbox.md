## Where Bate is ahead or right to differ

- OS limit on by default for reads and writes of a new bot (`PROTOCOL.md:246`). pi, omp have none; OpenClaw, nanobot, Hermes need opt-in (`OC:docs/gateway/sandboxing.md:9`, `nano:nanobot/agent/tools/shell_config.py:21`); nightly defaults to full (`NL:packages/contracts/src/ipc-agents.ts:40`) and confines writes only (`process-confinement.ts:674`).
- Profile also denies mach services, signals, Apple events, unix sockets and preferences (`appd/src/limit.rs:115-141`) and fails closed without `sandbox-exec` (`PROTOCOL.md:254`). nightly's profile is writes-only; nanobot's is deny-default but allows `mach*` and `ipc*` (`nano:nanobot/execution/sandbox.py:185-186`).
- Per-bot, per-kind levels, and `apple_change` can never be "Always" (`proto/src/permissions.rs:43-48`). omp's modes are global (`omp:docs/approval-mode.md:18`); omp default is `yolo` (`:25`).
- Secrets: keychain plus a local proxy that adds MCP tokens, so a token is never in the engine or the bot's folder (`appd/src/proxy.rs:1-4`). Only pi's p2 sandbox and Hermes via OpenShell do the same (`pi:apps/p2/plugins/envs/secrets.ts:1-3`, `Hermes:SECURITY.md:104-106`).
- Frames: own scheme, CSP with no network, window CSP, and a script that attacks from inside a real window (`window/ui/src/frameCheck.ts`, `window/check-frames.sh`). pi's CSP allows `connect-src https:` (`pi:apps/p2/plugins/artifacts/frame.ts:18`); CK's window has `"csp": null`.
- Local port refuses browser requests with `Origin` (`appd/src/hooks.rs:198-200`); no other app checked this.
- Escaped background processes cannot hold a tool call (`agentcore/src/tools.rs:238-250`, test `:374`). Chat is private by default with a code to pair, like OpenClaw and Hermes (`PROTOCOL.md:468`).
- Different on purpose: none found with a stated reason in Bate's code or issues.
