## Where Bate is ahead or right to differ

- Browser access on the local network (row 8): own TLS, shown fingerprint, short-lived code, hashed device cookie, and a block list of commands a paired device may not call (`lan.rs:431-447`). Hermes and nanobot serve plain HTTP (`desktop.md:136`; `runtime.py:502-515`); pi p2 is loopback only (`apps/p2/README.md:55`). OpenClaw is ahead only for native phone clients (pinning, QR).
- Page lock in the window: CSP without inline script, frames only on `botfile:`, a second check on navigation, new windows go to the browser (`tauri.conf.json:12`; `window/src/main.rs:198-205`). Its tests are in `main.rs`. Only nightly (`trusted-renderer.ts`) shows a comparable check; the others set `csp: null` (CopilotKit `tauri.conf.json:~13-27`) or were not checked.
- Chat features: retry, edit, fork, export, search and a 10,000-message virtual list all exist in the window (`Chat.tsx:61,246-260,318`). CopilotKit, nightly and nanobot lack edit of a sent message and chat export.
- Updates: idle-gated install and an Ed25519 check over version plus hash, so an old signed archive cannot pass as new (`update.rs:94-96`). Equal to nanobot and nightly in effect, simpler than Sparkle.
- No relay (row 9) is a stated choice: issue #36 "The project runs no relay"; pi, omp, nightly run one.
- Long-poll instead of WebSocket on the LAN page is a recorded shortcut (`lan.rs:31`), not a gap.
