## Where Bate is ahead or right to differ

- **Apple apps.** Only Bate offers Mail, Notes, Reminders, Calendar and Contacts as first-party tools with a fixed action table, every change asked every time, and model text passed only as `argv` (`appd/src/apple.rs:1-5`; `proto/src/permissions.rs:47`). OpenClaw and Hermes hand the model a CLI in a shell instead (`skills/apple-notes/SKILL.md:2-3`).
- **Permissions outside the main app.** Full Disk Access sits only in the helper "since every program it starts would inherit it" (`helper/src/messages.rs:1-3`); the helper's socket checks program path and signer (`appd/src/desktop.rs:101-109`). OpenClaw holds all grants in the main app (`docs/platforms/mac/permissions.md:12-25`); nightly makes OpenBot the responsible process (`docs/architecture/computer-use.md:11-15`).
- **User takeover cannot be faked by a page.** The take-over listener runs in an isolated world and counts only trusted events (`appd/src/browser.rs:36-41`). Nothing the other apps wrote says the same.
- **No debug port.** Chrome is driven over a pipe, so no local program can connect (`appd/src/browser.rs:263`; issue #30: "There is no debugging port or socket a bot's own programs could use"). Downloads are denied (`:357`).
- **Browser profile per bot, never the user's own.** Stated reason in `PROTOCOL.md:356`. Hermes and OpenClaw offer to copy or attach the real profile (`browser.md:298-313`; `docs/tools/browser.md:15,48`); Bate does not need that.
- **Dictation and read-aloud ask for no new permission and send nothing to the service.** Stated in `PROTOCOL.md:443,445`. OpenBot and nightly bundle models or Speech-framework code and the microphone entitlement for the same job.
